# SVANS-AI Desktop downloads

The site download button points to:

`/downloads/SVANS-AI-Desktop-Windows-v0.1.0.zip`

The generated ZIP contains the unpacked Windows desktop app. Users should:

1. Download the ZIP.
2. Extract it.
3. Run `SVANS-AI Desktop.exe`.

Note: desktop builds can be large. For production, host the ZIP through a release bucket, GitHub Release, or another download storage provider, then update `DESKTOP_DOWNLOAD_URL` in `app/page.tsx`.
